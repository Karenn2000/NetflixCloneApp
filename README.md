# StreamFlix 🎬

StreamFlix is a fully responsive, Netflix-inspired streaming platform clone built with React and TypeScript. It features a modern, dark-themed user interface, interactive movie cards, and functional search capabilities.

## ✨ Features

*   **Responsive Design:** Optimized for both Desktop and Mobile devices. Includes a dedicated mobile hamburger menu for smaller screens.
*   **Dynamic Hero Section:** A featured "Original" movie banner with "Play" and "More Info" buttons.
*   **Categorized Rows:** Movie content is organized into horizontally scrollable rows (Trending, Popular, Comedy, etc.) with left/right navigation arrows.
*   **Interactive Movie Cards:** Each card displays the movie poster, title, star rating, release year, and an "Add to Watchlist" (+) button.
*   **Real-time Search:** A functional search bar that filters movies and displays the results in a clean, responsive grid layout.
*   **Authentication Modals:** Fully designed UI modals for "Sign In" and "Sign Up" with form validation and tab switching.
*   **Custom Navigation:** Sticky navigation bar with links to Home, Browse, Search, Watchlist, and Login.

## 🚀 Technologies Used

*   **React** - For building the component-based user interface
*   **TypeScript** - For type-safe, robust code
*   **Vite** - For fast development and optimized builds
*   **CSS / CSS Modules** - For responsive styling and layout
*   **Lucide React** (or similar icon library) - For UI icons (Search, Play, Plus, etc.)
